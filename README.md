# Python for Mere Mortals

Plain-language guides to the Python programming language, written for
people who want to actually make the computer do things — no CS degree
required.

No jargon without an explanation. No "it's simple, just..." Every
concept starts with the *idea*, then the code.

## Start here

1. [What Python Is](what-python-is.md) — what it is, what it's good
   for, and what it isn't.
2. [Installing Python](installing-python.md) — Windows, Mac, and Linux,
   with checks that it worked.
3. [Your First Program](first-program.md) — from nothing to a working
   script, with checks along the way.

## The building blocks

4. [Variables and Types](variables-and-types.md) — storing text,
   numbers, lists, and labeled boxes of data.
5. [Control Flow](control-flow.md) — making decisions and repeating
   things: if, for, while.
6. [Functions](functions.md) — packaging reusable chunks of work.
7. [Files and Data](files-and-data.md) — reading and writing files,
   working with text and tables.

## Reference

8. [Troubleshooting](troubleshooting.md) — common errors, plain fixes.
9. [Glossary](glossary.md) — quick definitions, A to Z.

## Writing criteria

Every guide follows the same [writing criteria](criteria.md): plain
words, no hype, honest limits, and checkable steps.

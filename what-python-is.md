# What Python Is

Python is a programming language: a way to write instructions a
computer follows. You type plain-text commands, Python runs them. It's
one of the most widely used languages in the world, and it's where a
lot of people write their first real program.

## Why people pick Python

**It reads like English.** Compare printing a greeting:

```python
print("Hello, world!")
```

That's the whole program. Many languages need several lines of setup
to do the same thing.

**It comes with batteries.** Python includes ready-made tools for
files, dates, math, internet requests, and more — you don't install
extras for everyday tasks.

**It's everywhere.** Windows, Mac, Linux, Raspberry Pi. The same
script usually runs on all of them unchanged.

## What it's good for

- Automating boring computer chores (renaming files, processing
  spreadsheets, downloading things on a schedule).
- Small tools and utilities — the kind of scripts this repo's readers
  tend to accumulate.
- Data work: reading files, crunching numbers, making charts.
- Web backends, scripting inside other programs, and controlling
  hardware like a Raspberry Pi.

## What it isn't

- **Not the fastest language.** For heavy number-crunching or games,
  compiled languages (C, Rust, Go) run circles around it. For everyday
  tasks you won't notice.
- **Not the only tool.** Spreadsheets beat Python for one-off tables;
  shell scripts beat it for chaining commands. Use the right tool for
  the job.
- **Not magic.** Python does exactly what you tell it — including your
  mistakes. [Troubleshooting](troubleshooting.md) is part of the deal.

## Python 2 vs Python 3

You'll see this mentioned in old tutorials. Python 2 is retired —
has been since 2020. Everything here is **Python 3**. If a tutorial
says `print "hello"` without parentheses, it's Python 2 and outdated.
